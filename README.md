## 🚀 How to Run Locally in VS Code

### Option 1: Double Click (Simplest)
1. Open the `portfolio` folder on your computer.
2. Double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Live Server Extension in VS Code
1. Open VS Code.
2. Open the `portfolio` folder (`File > Open Folder...`).
3. Install the **Live Server** extension.
4. Right-click `index.html` and click **"Open with Live Server"**.
